# TOON 4.1.1 conformance provenance

SAFA targets the MIT-licensed TOON 4.1.1 specification at commit
`62f16b369408180f1faf1cba7da1b46d1f336f12`. CI strict-decodes these public fixtures with the
official TypeScript reference implementation at commit
`f06ddca16c8a4ccd091f33d7216c543e10a9c681` and verifies the official language-neutral fixture
corpus. Updating either pin requires a reviewed compatibility decision for `dev.safa.cli/v2`.
